# Sleep Habits and Academic Performance

## Probability and Statistics – Individual Project

### Project Overview
This project explores the relationship between students' sleep habits and their academic performance.

The study uses survey data collected from 30 participants to understand how sleep duration and sleeping patterns may influence students' academic results.

### Objectives
- To analyse students' sleeping habits.
- To understand the relationship between sleep duration and academic performance.
- To apply statistical methods to collected data.
- To present findings using statistical analysis and visualisations.

### Tools and Technologies
- R Programming
- RStudio
- Microsoft Excel
- Probability and Statistical Methods

### Dataset
Primary data collected through a survey of 33 participants.

### Project Type
Academic Project – Higher Diploma in Artificial Intelligence and Robotics.
